# lapis-rebuild

《佣兵传说》（Neo Dark Saver）数字考古与复刻项目。

本仓库用于长期保存、核验和整理 2003 年前后中国大陆《佣兵传说》、韩国 Neo Dark Saver / Lapis、日服 LAPIS Online 及相关版本的历史资料，并在证据充分后逐步开展个人怀旧用途的高还原复刻。

> 当前阶段：**资料考古 / 证据整理**。尚未进入正式客户端或服务端复刻。

## 项目目标

1. 找回 2003 年中国大陆《佣兵传说》原始客户端、补丁或杂志随刊光盘。
2. 保存国服截图、视频、攻略、网页和 UI 等一手证据。
3. 对照同期韩服 Neo Dark Saver，恢复战斗、职业、技能、地图和资源体系。
4. 利用后继 Lapis / 日服资料补齐已经失传的视觉和系统信息，但不把后期数据直接当成国服事实。
5. 首批重点完整复刻：**步兵/剑士**、**巫师**。

## 证据分级

| 等级 | 定义 | 用途 |
|---|---|---|
| A | 2003 年国服直接证据：客户端、补丁、国服截图/视频、官方报道、同期攻略 | 原版复刻的最高优先级依据 |
| B | 2003 年前后同期韩服 Neo Dark Saver 证据 | 补足国服缺失信息，需与 A 级交叉验证 |
| C | 后期 Lapis / 日服 LAPIS Online 继承资料 | 主要用于补美术、资源谱系、后继系统，不直接等同于国服 |

详见 [`docs/research/evidence-policy.md`](docs/research/evidence-policy.md)。

## 当前已确认

- 中国大陆运营：**北京汉娃娃软件**；开发商：**WizGate**。
- 17173 当前仍保留《佣兵传说》独立游戏条目，Game ID 为 **86**，并保有历史截图和视频索引。
- 2003 年至少存在两个重要国服客户端阶段：**5 月首批公测阶段**与**11 月 8 日“精灵派对”大版本**；11 月新版与旧版不兼容。
- 11 月版本官方曾称与当时韩国版本同步，因此同期韩服 Neo Dark Saver 是高价值对照样本。
- 韩服后继《Lapis》官网至今仍保存职业、技能、地图、战斗指南等结构化资料；其战斗采用 SRPG 风格和 Tick 行动机制。
- 国服旧客户端指纹线索包括 `NeoDark.exe`、注册表 `HKEY_CURRENT_USER\\Software\\NeoDarkSaver` 以及若干 `.Tdg` UI/资源文件名。
- 尚未取得可信的国服完整客户端、原始源码或服务端源码。

## 当前最高优先级

1. 追出 17173 历史视频 VID 的底层媒体文件并保存原始副本。
2. 搜索 2003 年 5 月和 11 月杂志随刊 CD/ISO 中的国服客户端。
3. 获取并分析韩服现行 Lapis 客户端，确认继承的 NDS 资源格式、音频和图形文件。
4. 建立国服步兵/剑士与巫师的职业、技能、动作、音效、装备、转职对照表。

## 原则

- 研究文档默认简体中文；文件/目录名使用英文。
- 韩文、日文资料保留原文名称，同时提供中文说明。
- 不把推测写成事实；每条关键结论尽量保留原始 URL、版本、地区和证据等级。
- 大型客户端、ISO、视频后续优先考虑 GitHub Releases / Git LFS 或仅保存哈希与来源，避免污染普通 Git 历史。
- 本项目以个人怀旧、研究和互操作性分析为目的；第三方美术、音频、客户端等素材的版权归原权利人所有。
