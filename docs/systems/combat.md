# 战斗系统基线

## 已确认的核心形态

《佣兵传说 / Neo Dark Saver》不是传统纯回合制，而是带实时行动节奏的战术型在线 RPG。

目前可确认的共同特征：

- 进入战斗后以角色/单位为操作核心。
- 角色存在移动范围与攻击范围。
- 地图呈 2D quarter-view / 战棋式空间布局。
- 主角之外存在佣兵、副将/副指挥官体系。
- 战斗节奏受行动资源（后继版明确称 Tick）影响。

## 后继 Lapis 官方战斗规则

`INHERITED-C`

MGame 当前官方指南明确描述：

1. 先选择要操作的角色。
2. 绿色区域显示移动范围。
3. 红色边界显示攻击范围。
4. 行动消耗 Tick。
5. 1 Tick 约 1.5 秒。
6. 强力技能需要更多 Tick。
7. Boss 以红星标识；部分战斗需击杀 Boss 才结束并结算经验。

## 国服验证状态

- 战棋/SRPG 操作形态：高置信，`CONFIRMED-A/B`
- 行动值/蓄力式节奏：高置信，`CONFIRMED-A/B`
- “Tick”术语：韩服后继官方确认，国服中文具体称呼待查
- `1 Tick = 1.5 秒`：当前仅作为 C 级参数，待通过国服录像逐帧测量

## 后续需要从视频/客户端量化

- 单位格/等距地图实际尺寸
- 普通移动每格耗时
- 普通攻击耗 Tick
- 各技能耗 Tick
- 行动槽恢复速率是否受属性影响
- 动画播放与伤害判定时点
- 攻击距离算法
- 移动范围算法
- 高低差/障碍/寻路规则
- 队伍最大规模
- 战斗开始与结束条件
- PVE/PVP 是否使用相同规则

## 原型复刻建议

第一版行为验证应只实现：

`选中单位 → 显示移动范围 → 移动 → 行动资源变化 → 普攻/技能 → 伤害 → 回到等待`

在拿到原视频或客户端前，不提前锁死最终数值。
