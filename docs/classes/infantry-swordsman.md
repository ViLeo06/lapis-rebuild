# 步兵 / 剑士 主档

> 用户首批重点复刻职业之一。

## 名称关系

国服资料主要使用：

- 步兵
- 部分页面/玩家语境中出现斗士、剑士

目前判断：用户记忆中的“剑士”与国服“步兵”高度对应。

状态：`CONFIRMED-A + INFERRED`

## 国服2003定位

- 近战物理
- 高 HP
- 重剑 / 剑盾
- 正面战斗能力强
- 魔法抗性相对弱

老玩家加点/培养资料显示：在满足装备要求后，常倾向继续投入 CON，提高耐久和前排能力。

## 已出现的早期技能线索

国服或旧版资料中出现过：

- 石头皮肤
- 献身
- 狂暴/强化攻击类技能
- 血之代价类技能

具体中文译名、等级、数值、技能图标必须继续按版本核验。
