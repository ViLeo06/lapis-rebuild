# 巫师 / 黑魔法师 主档

> 用户首批重点复刻职业之一。

## 国服职业定位

2003 年资料中，巫师与“魔法师”是两个不同职业：

- 魔法师：偏元素魔法，如火、水系。
- 巫师 / 黑魔法师：偏黑暗、诅咒、异常状态、召唤/特殊魔法。

状态：`CONFIRMED-A`

## 早期养成线索

国服老攻略明确出现：

- INT 是巫师核心属性之一。
- “毒雾”是重要技能/流派线索，并被描述为与 INT 强相关。

## 旧版/韩服谱系中出现的黑魔法技能线索

- 黑暗帷幕类
- 毒 / 毒雾
- Mana Drain / MP 吸收
- Ashes to Ashes 类攻击
- Medusa Eye / 美杜莎之眼类控制

这些名称来自不同年代/地区，需继续建立逐项对照。

## 后继 Lapis 对照

韩服后继职业名称常见 `사교` 等译名，对应黑魔法/邪教系职业。后继技能页面、技能图标和音效编号是重要 C 级资料，但具体技能等级、伤害、Tick、MP 消耗不可直接回填 2003 国服。

## 复刻需要最终确认

- 国服角色选择原画与男女版本
- 初始 Sprite、方向数与帧数
- 普攻是否使用法杖/远程魔法
- 毒雾原始范围、持续时间、伤害公式
- 各诅咒技能状态效果
- MP 消耗与 Tick
- 技能音效文件对应
- 转职名称、外观、装备限制
- INT 与魔攻/命中/异常状态的具体公式
