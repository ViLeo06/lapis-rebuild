## 直接观察到的 MVP 行为

1. **普通地图移动和镜头。** 单击可走地面后，画面立即出现目标标记；约 4–4.5 秒后的重新观察看到角色/跟随单位换位，建筑和街道随角色保持在画面中而平移。`cap-031`–`cap-035`、`cap-044`–`cap-049` 可作前后帧比对。观察间隔不是移动耗时测量，未恢复寻路网格、速度或碰撞算法。
2. **室内外切换。** 从街道靠近有台阶的建筑入口，随后可见与街道不同的道具屋/锻造屋室内；从锻造屋的下侧门槛行走约 4.5 秒后，画面换回铺石街道，见 `cap-055`→`cap-056`。这证明该次会话存在空间触发的场景切换表现，不能推出所有建筑的通用触发坐标。
3. **NPC 和服务菜单。** 道具屋店员的问候与三项选择见 `cap-037/038`。锻造师在靠近后左键点击会弹出带肖像的底部问候框；继续后即时画面显示“进行对话 / 修理装备 / 更换物品 / 不需要”。本轮只进入“进行对话”，没有操作修理、更换或物品格。
4. **锻造师后续文本。** `cap-055` 可读部分包含“以你的身份不能参加战争。请速回王宫。”。文字前半句被鼠标指针遮挡，未强行补全。这是当前会话的一条 NPC 对话；它不证明账号资格、剧情触发条件、战斗入口或服务器判定。
5. **户外 NPC。** `cap-057` 中的可见名为 `吉奥老师`，气泡写“冒险者，你好。”。靠近后单击及再次点击曾出现选择气泡，但本轮未打开可确认的完整对话菜单；不能据此认定该 NPC 没有进一步交互。
6. **小地图。** 本轮即时观察中 F8 将左上小地图隐藏，再次 F8 恢复。此开关没有单独保存一对 F11 原图；`cap-027` 的帮助叠层与 `cap-057` 只能辅助定位小地图。不要由这次开关推断地图数据来源或所有场景的显示规则。

顶栏 `龙兵` 栏可打开 `白银骑士` 信息卡（`4名`、体力 `200`、攻击 `5`、防御 `2`），其原始截图见同日较早的 [`manual-20260923-combat-session01.md`](./manual-20260923-combat-session01.md)。既有素材文件名中的 `battle-tab` 是采集时的误称；信息卡本身不代表已经进入战斗。
