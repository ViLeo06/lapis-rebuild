# ADR 0001: Web-first

Status: accepted by project owner, 2026-09-15.

Use Vite+TypeScript+Phaser in web/. Keep Python parsers and historical Godot diagnostics. End users should not need a Windows VM. A private self-contained HTML preview may embed generated resources; never deploy it publicly without separate authorization.

Training gameplay is a laboratory, not a reconstruction claim. Real skill names,IDs andMP costs come from recorded tables; damage,durations,enemies andtemporary effects are UNVERIFIED. G2-Web requires actual browser evidence, not merely build success.

The current container cannot resolve external development hosts and its Chromium navigation is denied by administrator policy. Do not bypass this policy. A bounded authorized private GitHub Actions job supplies public npm dependencies; normal CI uses synthetic assets. An explicit private-original smoke job may fetch and statically extract the hash-pinned known installer, never execute it. No tokens,passwords orprivate signedURLs enter the repository.
