# Assets 归档说明

本目录用于历史素材归档说明与后续合法保存的副本。

建议子目录：

- `screenshots/`
- `ui/`
- `characters/`
- `skills/`
- `maps/`
- `audio/`
- `video/`

## 当前策略

在尚未逐项下载、校验来源和版权状态前，不把网页上的第三方图片/音频直接批量提交进仓库。

每个实际归档素材至少应配套元数据：

- 原始 URL
- 来源站点
- 地区/版本
- 原发布日期（若可知）
- 抓取日期
- SHA256
- 证据等级
- 说明

大型视频、ISO、客户端优先使用 Release / Git LFS / 外部冷备份，并在仓库保留哈希与索引。
