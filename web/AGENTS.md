# Web 运行时专项规则

本文件补充仓库根目录 `AGENTS.md`，适用于 `web/`。用户当前更正与根目录安全规则优先。

## 1. 玩法边界

- 目标是《佣兵传说》的战棋/半回合制体验，不是普通地图上的实时砍杀。
- 非战斗地图与战场必须有独立的生命周期、坐标状态、行动权限与结算；不能只换标题就宣布完成战斗场景。
- 默认非战斗画面不画寻路路线、角色 bounds、锚点十字。保留 Debug Panel 的主动诊断开关，不删除诊断能力。
- 战斗可移动格提示属于战术界面，不等于寻路指引线；只应展示当前合法、可执行、未被单位占据的格子。
- 不无证据地改成固定“我方整队/敌方整队轮流”的完全回合制。当前行动槽的精确速度、消耗和并行规则仍待校准。
- 对练场与外城的训练入口关系、训练敌人、暂停/随时退出、AI、伤害和奖励都是可替换占位，必须明确标注，不能改名为原版已恢复。

## 2. 操作一致性

- 非战斗移动不受战斗行动槽约束。
- 战场移动按格子预算与占位校验；拒绝非法路径时不得先扣行动、MP 或改变位置。
- 行动执行期间禁止重复点击抢跑、途中改线或攻击取消移动。UI 禁用之外必须有状态层校验。
- 进入战斗前保存并在退出后恢复非战斗地图、脚底坐标、方向、镜头；奖励只结算一次。
- 战斗中的角色/地图/装备切换、存读档、任务推进应拒绝，而不是悄悄重置战斗。
- 读档需先完整校验目标地图、坐标、资源包、角色、任务和背包，再修改当前状态；坏输入应原子失败。
- 暂停和页面后台处理不得积累计时，在恢复时突然补算大量伤害。

## 3. 资源与证据

- SPR 相对 transparent skip 与 Body_ 方向 `S,SW,W,NW,N,NE,E,SE` 已经用户复测，不可回退。
- 原始资源、当前兼容实现、项目自写训练策略分别标注来源。
- 兼容实现里存在一条规则，不自动意味着它是 2003 国服的原始服务器规则。
- `ability.atr` 的字段值可以 VERIFIED，字段单位/完整公式未证实就不能 VERIFIED。
- 运行时不执行原 EXE/DLL/注入脚本。不得为方便预览而把私有资源或密钥公开。

## 4. 必须验证

修改战斗或场景切换后，至少检查：

1. 类型检查、单测和 production build。
2. synthetic 与可用时 private-original 浏览器回归。
3. 非战斗不显示路线和 bounds；外城进入对练场；返回恢复地图/坐标/方向/镜头。
4. 行动未就绪/执行中/暂停时连点或事件注入无效；合法移动受格数、障碍、单位占位限制。
5. 胜败、退出、奖励幂等、存档恢复、非法存档不污染状态。
6. 离线 HTML 无外网请求；桌面及窄屏无横向溢出。
7. 查看真实浏览器截图，并提供新版私人 HTML 给用户做玩法/视觉复核。

不能删掉旧测试场景来制造通过；流程改变时应保留原验收意图并更新实际操作。浏览器策略阻止执行时记录限制并在获准的 CI 环境验证，不绕过管理员策略。

30 分钟 soak 必须记录实际提交、内容和墙钟时长。旧版本或仅诊断动画的 soak，不等于新战斗生命周期已做完整稳定性测试。
