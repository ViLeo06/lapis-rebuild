# Reconstruction 复刻阶段说明

当前仓库尚处于数字考古阶段，本目录用于把未来复刻规格与历史研究分离。

建议后续按三类记录：

- `confirmed/`：由 A/B 级证据确认，可直接作为实现规格
- `inferred/`：多来源推断，需要在原客户端/录像中继续验证
- `unknown/`：关键但尚无证据的行为

## 第一阶段 Demo 建议

第一版不做完整 MMORPG，先验证“原味战斗循环”：

1. 标题/登录风格界面
2. 角色选择
3. 步兵/剑士
4. 一张经典地图
5. 选中单位与移动范围
6. Tick/行动值
7. 普通攻击
8. 3–5 个已确认技能
9. 一类普通敌人 + Boss
10. 原始风格 UI、音效、BGM

完成步兵后再加入巫师。

## 复刻优先级

视觉和行为优先于“现代化重设计”。在证据不足时宁可保留未知项，也不凭后期 Lapis 或现代游戏习惯擅自补规则。
