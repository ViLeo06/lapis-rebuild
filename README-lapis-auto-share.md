# 佣兵传说练级工具（分享版）

这是一个 Windows 本地自动练级小工具，当前版本针对你们正在玩的《佣兵传说》玩家服窗口客户端适配。

## 适用环境

- Windows 10 / 11（64 位）
- 游戏进程：NeoDark.exe
- 游戏窗口化运行
- 已验证客户区尺寸：1600 × 1200
- 窗口可以左右移动，但不要拖动边框改变客户区尺寸
- Python 3.11～3.13（64 位）
- AutoHotkey v2（64 位）

> 这是 UI 自动化工具：截图识别 + 键盘/鼠标输入。不会读游戏内存、不会注入 DLL、不会分析封包，也不包含反检测/绕过功能。请先确认你所在服务器允许自动化。

---

## 1. 安装

### 第一步：安装 Python

安装 64 位 Python 3.11～3.13。安装时建议勾选 “Add Python to PATH”。

### 第二步：安装 AutoHotkey v2

安装官方 AutoHotkey v2（64 位）。工具会自动寻找常见安装位置的 `AutoHotkey64.exe`。

### 第三步：安装依赖

解压本压缩包后，双击：

`安装依赖.bat`

第一次会创建本目录的 `.venv`，并安装：

- numpy
- opencv-python
- pillow

安装成功后，以后一般不需要重复执行。

---

## 2. 启动

1. 先启动《佣兵传说》并登录角色。
2. 保证只开一个游戏窗口。
3. 双击 `启动练级工具.bat`。
4. 点击“选择游戏窗口”。

如果启动失败，看同目录的 `launcher-error.log`。

---

## 3. 第一次校准

需要校准三个位置：

1. **人物脚下格子**：必须在战斗中校准。按提示把鼠标停在主角脚下的地面格子。
2. **红药位置**：鼠标停在红药物品格。
3. **蓝药位置**：鼠标停在蓝药物品格。

校准只记录相对于游戏客户区的坐标，所以游戏窗口之后左右移动不影响；但如果你改变窗口尺寸，需要重新校准。

---

## 4. 开跑前检查

先点：

`只观察`

正常应能稳定区分：

- 野外
- 战斗
- 胜利（VICTORY）

再点：

`开始3场试跑`

三场连续正常后，再用：

`开始循环`

---

## 5. 当前自动循环逻辑

### 脱离战斗 / 野外

1. 回到野外后立即右键红药。
2. 等 2 秒。
3. 右键蓝药。
4. 等怪物触发下一场战斗。

### 进入战斗

1. 按 `Tab`：主角回到脚下并居中。
2. 按 `X`：选择巫妖毒。
3. 等约 1 秒，左键点击主角脚下格子，展开技能范围。
4. 再等约 1 秒，再左键点击同一格，确认释放。

### 冗余补毒

如果第一轮后 8 秒仍然处于战斗，而且没有出现 VICTORY：

`X → 等1秒 → 左键脚下 → 等1秒 → 左键脚下`

只补这一轮，不无限重复。

### 胜利

一旦识别到 VICTORY，就停止后续补毒，等待回到野外，再从红药/蓝药流程重新开始。

---

## 6. 安全控制

- `F8`：全局急停。
- 工具里的“停止”按钮也可立即停止。
- 连续循环单次最长 24 小时。
- 场景长时间无法识别、输入发送失败、窗口尺寸变化等异常会安全停机。
- HP/MP 数字只是视觉估计，仅显示，不参与战斗控制。
- **当前没有自动死亡/复活流程。** 如果角色死亡，需要人工复活后重新开始循环。

---

## 7. 日志与异常截图

日志目录：

`logs\`

主日志：

`logs\lapis-auto.log`

每次“3 场试跑”或“开始循环”都会生成：

`logs\sessions\<session-id>\`

其中包括：

- `metadata.json`：窗口、坐标、配置等
- `events.jsonl`：场景变化、动作发送、错误
- `summary.json`：最终停止原因和场次
- `screenshots\*-start.jpg`：启动截图
- `screenshots\*-periodic.jpg`：每 10 分钟定时截图
- `screenshots\*-abnormal-stop.jpg`：异常退出最后一帧

以后出 Bug，优先把对应 session 整个文件夹发给维护者。

## 8. 分享版说明

本压缩包**不包含**原作者机器上的：

- 游戏账号信息
- profile.json / 已校准个人坐标
- logs / 历史截图
- session token
- Python 虚拟环境
- 原始游戏录屏

分享版为了减小体积，也不携带个人录屏提取的整帧模板。当前稳定识别使用玩家服固定 UI 特征来判断 FIELD / BATTLE / VICTORY，并已按现有 1600×1200 客户端流程验证。

如果服务器 UI、分辨率或快捷键布局不同，需要重新适配，不能保证直接可用。

## 9. 常见问题

**选择不到游戏窗口**  
确认只开一个《佣兵传说》窗口，进程应为 NeoDark.exe。

**“只观察”一直未知**  
先确认窗口客户区是 1600×1200，并且没有大窗口遮住游戏 HUD。

**点击位置不对**  
重新校准三点；尤其人物脚下格子必须在战斗中校准。

**一直不动作**  
看 `logs\lapis-auto.log` 和最新 `logs\sessions\...\summary.json`。

**人物死了**  
当前版本不会自动复活。人工复活后重新开始循环。

**换电脑/发给别人后需要重新校准吗？**  
需要。不要复制别人的 profile.json 坐标。
